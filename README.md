# learn_python
Консольный калькулятор на Python с поддержкой базовых арифметических операций, вычисления логарифмов и тригонометрических функций. Программа автоматически адаптируется под региональные стандарты ввода чисел (точка/запятая) и сохраняет историю сессии в файл.

- **Математический функционал**:
  - Бинарные операции: сложение (`+`), вычитание (`-`), умножение (`*`), деление (`/`).
  - Вычисление логарифма с произвольным основанием (`log`).
  - Тригонометрия: вычисление синуса угла в радианах (`sin`).
- **Надежность и валидация**:
  - Автоматическое определение разделителя дроби (поддержка ввода чисел как с точкой `1.5`, так и с запятой `1,5` через модуль `locale`).
  - Контроль математических ограничений (проверка деления на ноль, областей определения логарифма и экстремально больших чисел).
- **Логирование и история**:
  - Просмотр истории вычислений текущей сессии прямо в консоли.
  - Автоматическая выгрузка логов в файл `calc_console_log.txt` рядом со скриптом при выходе из программы.
- **Удобство управления**:
  - Быстрый вызов истории (команда `h` или `р`) и выхода (команда `q` или `й`) на любом этапе работы.

## Технические требования

Для запуска программы требуется установленный интерпретатор **Python 3.x**. 
Все используемые модули являются стандартными («из коробки»), поэтому установка дополнительных библиотек (через `pip`) **не требуется**.

Используемые модули: `math`, `locale`, `sys`, `os`, `datetime`.
